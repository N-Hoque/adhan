# Adhan

A prayer time scheduler that automatically plays the Adhan when each prayer time arrives. Designed to run as a background service on Linux (via systemd), macOS, or Windows — and was originally built for a Raspberry Pi.

## Requirements

- Audio files for playback (sourced by you — see [Setup](#setup))
- A valid `settings.yaml` configuration file (generated by the program — see [Setup](#setup))

## Setup

### 1. First run

Run the program once to initialise the config directory:

```sh
adhan run
```

This creates the following structure in your platform's config directory:

| Platform | Path |
|:--|:--|
| Linux | `~/.config/adhan/` |
| macOS | `~/Library/Application Support/adhan/` |
| Windows | `%APPDATA%\adhan\` |

The directory layout is:

```
adhan/
├── settings.yaml       ← calculation config (generated in step 2)
└── audio/
    ├── fajr/           ← place Fajr adhan audio files here
    └── normal/         ← place standard adhan audio files here
```

### 2. Generate a config file

```sh
adhan generate <METHOD>
```

This writes a `settings.yaml` to your config directory using the given calculation method. You will need to edit it afterwards to set your coordinates.

**Available methods:**

| Method | Authority |
|:--|:--|
| `muslim-world-league` | Muslim World League |
| `egyptian` | Egyptian General Authority of Survey |
| `karachi` | University of Islamic Sciences, Karachi |
| `umm-al-qura` | Umm al-Qura University, Makkah |
| `dubai` | UAE |
| `moonsighting-committee` | Moonsighting Committee Worldwide |
| `north-america` | ISNA |
| `kuwait` | Kuwait |
| `qatar` | Qatar |
| `singapore` | Singapore, Malaysia, Indonesia |
| `tehran` | Institute of Geophysics, University of Tehran |
| `turkey` | Diyanet (approximation) |
| `other` | No preset — set angles manually |

If you are unsure which to use, `moonsighting-committee` is a good general-purpose choice for most locations.

**Example `settings.yaml`:**

```yaml
coordinates:
  latitude: 51.5074
  longitude: -0.1278
parameters:
  # ... generated values for your chosen method
```

### 3. Add audio files

Place your audio files inside the appropriate subdirectory:

- `audio/fajr/` — played at Fajr
- `audio/normal/` — played at all other prayers

Any number of files can be placed in each folder. One will be chosen at random each time. Most common audio formats are supported (MP3, OGG, WAV, FLAC).

> Audio files are not bundled with the program and must be sourced by you.

## Running

### Directly

```sh
adhan run
```

Starts the scheduler. It sleeps until the next prayer time, plays the Adhan, then waits for the one after that. At midnight it reloads the timetable for the new day.

To use a specific audio output device:

```sh
adhan run <DEVICE_NAME>
```

### As a systemd service (Linux / Raspberry Pi)

Create `/etc/systemd/system/adhan.service`:

```ini
[Unit]
Description=Adhan prayer time scheduler
After=sound.target

[Service]
ExecStart=/usr/local/bin/adhan run
Restart=on-failure
RestartSec=10

[Install]
WantedBy=default.target
```

Then enable and start it:

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now adhan
```

View logs:

```sh
journalctl -u adhan -f
```

## Commands

| Command | Description |
|:--|:--|
| `adhan run [DEVICE]` | Start the scheduler. Optionally specify an output device |
| `adhan test [DEVICE]` | Play a test adhan. Pass `--use-fajr` / `-f` to test the Fajr adhan specifically |
| `adhan timetable` | Print today's prayer timetable |
| `adhan generate <METHOD>` | Generate a `settings.yaml` for the given calculation method |
| `adhan list devices` | List available audio output devices |
| `adhan list hosts` | List available audio hosts |

## Raspberry Pi

The program runs well on a Raspberry Pi 3 or newer. Raspberry Pi 2 (Model B) is supported but not actively tested. Pi 0 and Pi 1 are not supported.

A `compile.sh` script is provided for cross-compiling and deploying directly to a Pi over SSH:

```sh
# Build for Raspberry Pi 2
./compile.sh -t 2

# Build and deploy to Raspberry Pi 2
./compile.sh -t 2 -u <USERNAME> -a <PI_IP> -d

# Build and deploy to Raspberry Pi 3 or newer
./compile.sh -t 3 -u <USERNAME> -a <PI_IP> -d
```

The Pi must be reachable over SSH. Once deployed, the systemd service instructions above apply as normal.
